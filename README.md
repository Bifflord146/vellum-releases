# Vellum

A PDF viewer, editor and signer for Windows. You can:
- read PDFs, fill in forms, and type or tick anywhere on a flat PDF (calendars too)
- mark up, edit the real text, and rearrange, merge or split pages
- convert Word, Excel and other files to PDF, OCR scans, and redact
- sign with a real digital signature

It works offline and is part of the Nocturne apps. No telemetry, no account.

## Download

**[Download Vellum-Setup.exe](https://github.com/Bifflord146/vellum-releases/releases/latest/download/Vellum-Setup.exe)** (Windows 10/11, 64-bit)

Run it. It installs for your Windows account only, with no administrator prompt, and adds Vellum to the Start menu under **Nocturne**. It can also add Vellum to "Open with" for PDFs, but it never makes Vellum the default.

To remove it, go to Settings › Apps › Installed apps › Vellum › Uninstall. Your settings, saved signatures and signing key are kept, in case you reinstall.

> Windows may say "Windows protected your PC" because the installer isn't code-signed. Click **More info**, then **Run anyway**.

## Updates

Vellum updates itself:
- It checks this page shortly after it opens and every few hours.
- It downloads a newer version in the background.
- It installs the new version when you close Vellum.

Nothing else is sent anywhere.

This repository holds the built app only; there is no source code here.
